# Five-minute demonstration

Prepare: database, web and separate worker running; private requester/reviewer/admin sessions in separate browser profiles. Use fictional files only.

1. (0:00–0:45) Public overview: explain AI-assisted learning contribution, mock label and no-orders boundary.
2. (0:45–1:45) Requester uploads clean.pdf. Open original PDF and field evidence. Save an explicit human review reason and validate. Mention exact decimal rounding.
3. (1:45–2:30) Submit. Reviewer checks assigned request and records a reasoned approval. Show one internal purchase record.
4. (2:30–3:30) Administrator first enables two local receiver failures, then repeat with a new fictional quotation. Inspect delivery attempts 503 → 503 → 200. Show one Purchase and one receiver event, not three effects.
5. (3:30–4:15) Use high-value.pdf: one approval is insufficient; a second distinct reviewer is required. Show why requester self-approval is blocked.
6. (4:15–5:00) Upload arithmetic.pdf or scanned.pdf. Show validation/manual-entry or terminal failure rather than pretending extraction always works. Open test/evaluation evidence and explain what remains unverified.

Never reveal passwords, provider keys or environment files during screen-sharing. Do not claim the live provider was evaluated when using mock. Stop the local failure simulation afterwards by setting failures to zero.
